# Brief template

**<Meeting title>**, <day, time, length>
With: <names, and their organisation if it is not the user's>

**Why this meeting**: one sentence. Use the agenda if there is one, otherwise infer it from
the latest email and say that you inferred it.

**Where things stand**
- Three to five bullets: what was agreed last time, what is open, what changed since.

**Open questions for the user**
- Things the user may be asked, or should ask.

**Useful numbers and dates**
- Only ones that came up in the sources, each with its source.

**Sources**: the emails, events and documents you used.
